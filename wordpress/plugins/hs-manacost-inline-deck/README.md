# Manacost inline deck images

Изолированный модуль для `hs-manacost.ru` и темы Newspaper.

- добавляет одну кнопку в Classic Editor;
- создаёт изображение через серверный API Kolodahs;
- загружает результат в медиатеку WordPress;
- вставляет компактный `[hs_deck_link image_id="…"]…[/hs_deck_link]`;
- открывает отдельный быстрый lightbox с кнопкой копирования кода;
- не меняет файлы Newspaper и не пересекается со старым менеджером колод.
