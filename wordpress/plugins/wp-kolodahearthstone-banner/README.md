# KolodaHearthstone: Banner

Плагин для создания красивых баннеров с иконкой телеграма и кастомным шрифтом в стиле спойлеров.

## Установка

1. Активируйте плагин в WordPress
2. Убедитесь, что файл `Telegram_2019_Logo.svg_.webp` находится в папке `assset/`
3. Убедитесь, что шрифт `2318-font.otf` находится в папке `wp-kolodahearthstone-decks/font/`

## Использование

### Через TinyMCE

1. В редакторе нажмите кнопку "Баннер"
2. Введите заголовок
3. Выберите цвет баннера
4. При необходимости укажите ссылку
5. Выберите, показывать ли иконку Telegram
6. Введите содержимое баннера
7. Нажмите "OK"

### Через шорткод

```
[banner title="Подпишитесь на наш Telegram" color="blue" url="https://t.me/channel" icon="telegram"]
Получайте самые свежие новости и обновления прямо в Telegram!
[/banner]
```

## Параметры

- `title` - Заголовок баннера (обязательно)
- `color` - Цвет баннера (default, blue, green, red, purple, orange, yellow, brown)
- `url` - Ссылка (необязательно, если указана, баннер становится кликабельным)
- `icon` - Показывать иконку Telegram (telegram или false)

## Доступные цвета

- `default` - бежевый (по умолчанию)
- `blue` - синий
- `green` - зеленый
- `red` - красный
- `purple` - фиолетовый
- `orange` - оранжевый
- `yellow` - желтый
- `brown` - коричневый

## Особенности

- Кастомный шрифт для заголовка
- Иконка Telegram справа
- Адаптивный дизайн для мобильных устройств
- Поддержка ссылок (баннер становится кликабельным)
- Поддержка форматирования текста внутри баннера
